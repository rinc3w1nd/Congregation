# CONGREGATION — Marrow Bay & Corruption

The town map is the hero element of the screen and the game's primary
progress readout. One `<svg>` generated by `src/town.js` from a fixed layout
table + seeded jitter (`mulberry32`), restyled per corruption stage. Bounded
element count: **< 1500 elements** — buildings are simple compound shapes,
not architectural drawings.

## Geography

Portrait composition, bay at the bottom. The water occupies the lower ~28%;
the town rises up the slope; the Verge scatters along the edges and hilltop.
Somewhere under the bay: **the Bore** — invisible at stage 0, undeniable by
stage 3.

## The five corruption stages

Stage = `corruptionStage(state)` (0–4, lifetime-Dread thresholds in
`balance.js`). Restyle via a `data-stage` attribute on the SVG root + CSS
custom properties — **not** by regenerating geometry — so transitions can
cross-fade over ~4s and feel noticed-too-late rather than announced. Per-stage
deltas are cumulative unless stated.

### Stage 0 — Quaint
Warm dusk palette (peach sky → deep-blue bay), amber windows (~90% lit),
chimney smoke curling inland, gulls (3–4 arc glyphs), lighthouse beam sweeping
lazily, boats scattered at natural angles.

### Stage 1 — Off
Palette desaturates ~15%, sky greens almost imperceptibly. ~20% of windows go
dark — scattered, no pattern. The gulls are gone. Chimney smoke now drifts
**toward the bay**, all of it. One boat has turned to face the open sea.

### Stage 2 — Wrong
Teal-green cast; the tide line sits visibly higher (waterline path moves up).
Every remaining lit window flickers occasionally (CSS animation, desynced).
All boats now point at the **same spot in the bay**. The clocktower's hands
stop at 3:14. Thin dark tendrils appear along the shoreline. Doors of three
buildings stand ajar (door rects offset). ~50% windows dark.

### Stage 3 — Consumed
Purple-black palette; ~85% windows dark, the Gutted Lantern's the stubborn
last warm one. Tendrils web up between buildings and along streets; buildings
nearest the shore lean 1–2° toward the water (per-building rotate). A dark
disc is visible in the bay — the Bore — with a faint slow ring pulse. The
lighthouse beam now sweeps *fast*, hunting. Streetlamps glow the accent color.

### Stage 4 — The Choir
Near-black. **Every** window lights at once in the accent color — everyone is
awake, standing at their windows. Tendrils pulse gently. The town geometry
breathes: whole-map scale oscillation 1±0.004, ~7s period — and the UI panels
breathe with it (see [UI.md](UI.md)). The Bore is a wide mouth of concentric
rings. The lighthouse beam points straight down into it, fixed. Gazette
ticker repeats a single headline.

## Implementation notes

- One `buildTown()` producing geometry once per session; stage changes touch
  only classes/attributes/custom properties. Keep per-building groups
  (`<g id="b-church" class="bld" data-district="oldtown">`).
- Namespace all SVG ids (`b-`, `grad-`, `fx-` prefixes) — the studio codebase
  learned the hard way that SVG ids colliding with control input ids silently
  break things.
- Windows: `class="win"`, lit-state chosen by seeded hash of (buildingId,
  windowIndex, stage) so the *same* windows go dark for everyone at a given
  stage — determinism is a pillar.
- Notables' buildings get a subtle marker when their conversion is available
  (soft accent halo), and a converted style after (window state diverges from
  district norm — converted houses are lit *too early* at stage 3+).
- Filters: cheap only (`feGaussianBlur` on glows at most); the map is live DOM
  SVG, but perf on mid phones matters. No per-frame JS animation for ambience —
  CSS animations/transitions only. JS may toggle classes.
